## IntelliSort

IntelliSort began as a way to make algorithms more understandable, but I pushed it further than a classroom visualizer. I wanted the project to connect visual intuition, asymptotic reasoning, and empirical runtime behavior.

I built React-based visualizations that compare sorting algorithms across inputs and expose how time complexity and data shape influence performance. Then I trained a lightweight ML model to estimate runtime behavior from input size and structural characteristics.

That combination made the project more interesting to me than a standard demo. It became a tool that shows both what the algorithm is doing and what performance trends you should expect.

The project reflects a pattern I enjoy: turning abstract technical concepts into interactive systems that are measurable, explainable, and useful.
