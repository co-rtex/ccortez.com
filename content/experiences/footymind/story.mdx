## FootyMind

FootyMind is a sports analytics application built around the full modeling loop: feature engineering, model training, and validation across different seasons so results do not collapse under distribution shift.

I engineered features from historical match data and trained classification pipelines with scikit-learn. I then evaluated season-over-season performance to understand whether the model generalized or was simply overfitting to one dataset slice.

That evaluation work was important because sports data can be noisy, context-sensitive, and easy to over-interpret. The project pushed me to think about model discipline, not just accuracy snapshots.

FootyMind shows how I approach ML work when the domain is interesting but the engineering expectations still need to be rigorous.
